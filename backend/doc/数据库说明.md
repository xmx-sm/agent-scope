# 数据库说明

- 数据库：PostgreSQL 17，库名 `agent_scope`
- 连接：`postgresql+asyncpg://mx:990108@127.0.0.1:5432/agent_scope`
- 建表：后端启动时 `Base.metadata.create_all` 自动创建缺失表
- **已有表新增列不会自动补**，需要手工 `ALTER TABLE ... ADD COLUMN ...`

## 修改约定

1. 修改 `value_type` 时同步调整 `admin_service.async_update_config` 的校验分支。
2. 新增权限点时修改 `app/permissions.py`，并将 `DEFAULT_ROLE_PERMISSIONS` 同步；前端权限矩阵会自动展示。
3. 调整种子数据不会影响已初始化的数据库；需要重置时手工清表后重启。

## v0.2.0 变更

### users 新增列

| 列 | 类型 | 说明 |
|---|---|---|
| avatar | varchar(500) | 头像 URL；启动时执行 `ADD COLUMN IF NOT EXISTS` 幂等迁移 |

### 新表 user_permission_states

| 列 | 类型 | 说明 |
|---|---|---|
| user_id | varchar(36) PK | FK users.id，ON DELETE CASCADE |
| granted | text | 超管单独授权，JSON 数组 |
| shrunk | text | 被上级/本人收缩的权限，JSON 数组，只增不减 |
| temp_grants | text | 超管临时越级授权，JSON：`[{"permission","expires_at"}]` |
| updated_by | varchar(36) | 最后操作人 |
| updated_at | timestamptz | 更新时间 |

### 新增配置项

`default_avatar`、`rate_limit_enabled`、`login_max_attempts`、`login_window_seconds`、
`register_max_attempts`、`register_window_seconds`、`default_page_size`、`status_refresh_seconds`。

配置分组不落库，由 `app/services/config_service.py::CONFIG_DEFINITIONS` 统一维护，
接口返回时补 `group` / `default` 字段。

### 权限升级兼容

启动时自动：

1. 超管角色权限更新为全部权限点；
2. 普通角色补齐 `permissions.self`；
3. 管理员角色补齐 `permissions.team`；
4. 剔除普通角色中的超管专属权限点。

## v0.3.0 新增：menus

| 列 | 类型 | 说明 |
|---|---|---|
| id | varchar(36) PK | UUID |
| key | varchar(80) 唯一、索引 | 菜单标识，如 `menu.status` |
