# backend 参数说明

> **所有公开服务函数统一只接收一个 `params: dict`。**
>
> 全部函数的路径、入参、功能说明见自动生成的
> [服务函数索引.md](./服务函数索引.md)。
> 本文只说明约定、通用键与目录归属。

---

## 一、服务函数签名

```python
async def async_xxx(params: dict) -> Any:
    """功能说明。

    参数：session / user / user_id / ...
    """
    session = params["session"]
    ...
```

约定：

- 公开服务函数只接收一个字典，不再使用位置参数。
- 必填键缺失抛 `KeyError`，属于编码错误，开发期暴露。
- 可选键统一 `params.get(...)`。
- 不读取 `Request`；IP、User-Agent 等由路由层解析后放入字典。
- 以下划线开头的内部辅助函数允许显式参数，但必须有 docstring 说明。
- 每个函数必须有 docstring；公开入口必须写明功能与参数键。
- 前端/HTTP 不直接调用服务函数，只通过路由层。

---

## 二、通用字典键

| 键 | 类型 | 说明 |
|---|---|---|
| `session` | `AsyncSession` | 数据库会话 |
| `user` / `viewer` / `operator` / `actor` | `User` | 当前操作人 |
| `data` | `dict` | 已通过 Pydantic 校验的请求体 |
| `user_id` / `target_id` / `ancestor_id` | `str` | 目标用户 ID |
| `key` / `value` / `default` | 任意 | 配置项参数 |
| `permissions` | `list[str]` | 权限键列表 |
| `page` / `page_size` | `int` | 分页 |
| `library_id` / `document_id` | `str` | 知识库资源 ID |
| `peer` / `session_hint` | `str` | A2A 伙伴与远端会话标识 |
| `job_id` / `conversation_id` | `str` | 定时任务 / 会话 ID |

## 三、返回与异常

路由层统一包装：

```json
{"code": 200, "data": ..., "msg": "success"}
```

业务失败抛 `ApiError`：

```python
raise ApiError("账号或密码错误", code=401)
raise ApiError("没有权限", code=403)
raise ApiError("尝试频繁", code=429, status_code=429)
```

| code | 语义 |
|---|---|
| 200 | 成功 |
| 400 | 参数/业务校验失败 |
| 401 | 未登录、令牌失效、账号密码错误 |
| 403 | 无权限、账号禁用 |
| 404 | 资源不存在 |
| 429 | 限流 |
| 503 | 维护模式 |

`ApiError` 默认 HTTP 200；`401/403/404/429/503` 按约定使用真实状态码。

## 四、目录归属

```text
services/
├── account/
│   ├── auth/
│   └── user/
├── access/
│   ├── permissions/
│   ├── tools/
│   └── security/
├── system/
├── config/
├── menu/
├── llm/
├── integrations/
└── agent/
    ├── runtime/
    ├── conversation/
    ├── knowledge/
    ├── resources/
    ├── collaboration/
    ├── automation/
    ├── media/
    ├── config/
    └── analytics/
```

新增服务函数时：

1. 放入对应领域/子域。
2. 只接收 `params: dict`。
3. 写清楚 docstring：功能 + 参数键。
4. 重新生成《服务函数索引.md》。
5. 同步《接口说明.md》《开发记录.md》。
