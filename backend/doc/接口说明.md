# 后端接口说明

- 基础前缀：`/api`
- 统一响应：`{"code": 200, "data": ..., "msg": "success"}`
- 业务失败：HTTP 200，`code` 为 400/403/404/503
- 未登录 / Token 失效：HTTP 401，`code=401`
- 鉴权头：`Authorization: Bearer <access_token>`

## 系统

### GET /api/health

健康检查。

```json
{"code": 200, "data": {"status": "ok"}, "msg": "success"}
```

### GET /api/public/site

登录/注册页公开信息（无需鉴权）。

```json
{
  "code": 200,
  "data": {
    "site_name": "Agent Scope Platform",
    "site_description": "轻量级权限管理平台",
    "allow_register": true
  },
  "msg": "success"
}
```

## 认证

### POST /api/auth/register

```json
{
  "username": "wangwu",
  "nickname": "王五",
  "password": "990108",
  "email": "wangwu@example.com",
  "phone": null
}
```

- `username` 2-50 字符，唯一
- `password` 最少 6 位（受 `password_min_length` 配置影响）
- `nickname` 不填默认等于用户名，且必须唯一
- `email` / `phone` 选填，填写则唯一
- 受默认配置 `allow_register` 控制

成功返回 `{user, tokens}`，`tokens` 内含 `access_token` / `refresh_token` / `user`。

### POST /api/auth/login

```json
{"account": "MX", "password": "990108"}
```

`account` 支持用户名、昵称、邮箱、手机号。

成功：

```json
{
  "code": 200,
  "data": {
    "access_token": "...",
    "refresh_token": "...",
    "user": {
      "id": "uuid",
      "username": "MX",
      "nickname": "MX",
      "email": "mx@example.com",
      "phone": null,
      "role": "super_admin",
      "leader_id": null,
      "is_active": true,
      "created_at": "...",
      "updated_at": "..."
    }
  },
  "msg": "登录成功"
}
```

错误：账号或密码错误（401）、账号被禁用（403）、维护模式（503）。

### POST /api/auth/refresh

```json
{"refresh_token": "..."}
```

返回与登录相同结构的 `{access_token, refresh_token, user}`。

### GET /api/auth/me

需要鉴权。返回当前用户与角色权限：

```json
{
  "code": 200,
  "data": {
    "user": {"id": "...", "username": "MX", "role": "super_admin", "...": "..."},
    "permissions": ["dashboard", "profile", "admin.users", "admin.settings", "admin.permissions"]
  },
  "msg": "success"
}
```

### POST /api/auth/change-password

```json
{"old_password": "990108", "new_password": "123456"}
```

## 个人中心

### PUT /api/profile

```json
{"nickname": "新昵称", "email": "new@example.com", "phone": null}
```

三个字段均可选；传 `null` 表示清空邮箱/手机号。

## 管理端

- 用户管理（`/admin/users*`）：需要 `admin.users` 权限，超级管理员始终放行
- 统计、配置、权限矩阵：仅 `super_admin`
- 非超管可以看到/管理除超管以外的账号，不能创建、修改、删除超管或授予超管角色

### GET /api/admin/stats

```json
{
  "users": {
    "total": 3,
    "active": 3,
    "by_role": {"super_admin": 1, "admin": 1, "user": 1}
  }
}
```

### GET /api/admin/users

查询参数：

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| page | int | 1 | 页码 |
| page_size | int | 10 | 每页 1-100 |
| keyword | str | "" | 用户名/昵称/邮箱/手机号模糊搜索 |
| role | str | "" | 角色过滤 |

返回 `{items, total, page, page_size}`，每项额外带 `leader_name`。

### POST /api/admin/users

```json
{
  "username": "zhaoliu",
  "password": "990108",
  "nickname": "赵六",
  "email": null,
  "phone": null,
  "role": "user",
  "leader_id": null,
  "is_active": true
}
```

### PUT /api/admin/users/{user_id}

可传字段：`nickname`、`email`、`phone`、`role`、`leader_id`、`is_active`。
用户名不可修改。系统保证至少保留一名启用状态的超级管理员。

### DELETE /api/admin/users/{user_id}

不能删除当前登录账号；删除前会自动解除下属的汇报线。

### POST /api/admin/users/{user_id}/reset-password

```json
{"new_password": "123456"}
```

### GET /api/admin/configs

返回配置数组：

```json
[
  {
    "key": "allow_register",
    "value": true,
    "label": "开放注册",
    "description": "关闭后注册接口拒绝新用户",
    "value_type": "bool",
    "updated_at": "..."
  }
]
```

### PUT /api/admin/configs/{key}

```json
{"value": false}
```

按 `value_type` 校验：`bool` / `int` / `string`。

### GET /api/admin/permissions

```json
{
  "permissions": [
    {"key": "dashboard", "name": "工作台", "group": "基础"},
    {"key": "admin.users", "name": "用户管理", "group": "管理"}
  ],
  "roles": [
    {"role": "super_admin", "permissions": ["..."], "editable": false},
    {"role": "admin", "permissions": ["dashboard", "profile", "admin.users"], "editable": true},
    {"role": "user", "permissions": ["dashboard", "profile"], "editable": true}
  ]
}
```

### PUT /api/admin/permissions/{role}

```json
{"permissions": ["dashboard", "profile", "admin.users"]}
```

- 仅支持 `admin` / `user`；`super_admin` 固定全部权限
- 未知权限键会被过滤

## 错误码

| code | 含义 |
|---|---|
| 200 | 成功 |
| 400 | 参数/业务校验失败 |
| 401 | 未登录、Token 失效、账号密码错误 |
| 403 | 无权限、账号禁用 |
| 404 | 资源不存在 |
| 503 | 维护模式 |

## v0.2.0 新增接口

### PUT /api/profile

新增 `avatar` 字段（http(s) URL 或站内路径，空字符串清空）：

```json
{"nickname": "MX", "avatar": "https://example.com/a.png"}
```

### GET /api/permissions/mine

当前登录用户权限详情：

```json
{
  "role": "user",
  "role_permissions": ["dashboard", "permissions.self", "profile"],
  "granted": [],
  "shrunk": ["profile"],
  "temp_grants": [{"permission": "system.status", "expires_at": "2026-11-24T00:00:00Z"}],
  "base": ["dashboard", "permissions.self", "profile"],
  "effective": ["dashboard", "permissions.self", "system.status"],
  "shrunk_active": ["profile"],
  "shrinkable": ["dashboard", "permissions.self"],
  "catalog": [{"key": "dashboard", "name": "工作台", "group": "基础"}]
}
```

### POST /api/permissions/mine/shrink

```json
{"permissions": ["profile"]}
```

仅能收缩当前有效权限；临时授权不可收缩。

### GET /api/permissions/team

需要 `permissions.team`。返回管理链上全部下属（含间接下属）及其有效权限、可收缩权限、临时授权。

### POST /api/permissions/team/{user_id}/shrink

```json
{"permissions": ["profile"]}
```

只能操作自己的下属；不能收缩超管；不能收缩临时授权。

### GET /api/admin/users/{user_id}/permissions

超管查看任意用户权限详情（结构同 `/permissions/mine`）。

### PUT /api/admin/users/{user_id}/permissions

超管全量设置：

```json
{
  "granted": ["permissions.team"],
  "shrunk": ["profile"],
  "temp_grants": [
    {"permission": "system.status", "expires_at": "2026-11-24T00:00:00Z"}
  ]
}
```

- `granted` / `shrunk` 只接受可分配权限点
- `temp_grants` 可包含 `system.status` 等由 `require_permission` 保护的只读权限（越级授权）；用户管理/默认设置仍固定超管专属
- 过期时间必须晚于当前时间
- 被设置对象不能是超级管理员

### GET /api/system/status

需要 `system.status` 有效权限（超管或临时授权）。返回：

```json
{
  "app": {"uptime_seconds": 120, "python": "3.14.8"},
  "system": {"system": "Linux", "node": "host", "boot_time": "..."},
  "cpu": {"usage_percent": 12.5, "logical": 16, "physical": 8, "load_avg": [0.1, 0.2, 0.3]},
  "memory": {"total": 0, "used": 0, "percent": 20.0, "swap_percent": 1.0},
  "disk": {"partitions": [{"mountpoint": "/", "percent": 23.6}]},
  "gpu": [{"name": "NVIDIA GeForce RTX 3060", "memory_used_mb": 1024, "utilization_percent": 0}],
  "network": {"primary_ip": "192.168.1.10", "interfaces": [], "bytes_sent": 0},
  "redis": {"connected": true, "rate_limit_backend": "redis", "rate_limit_buckets": 1},
  "database": {"connected": true, "response_time_ms": 0.5}
}
```

### POST /api/admin/configs/{key}/reset

恢复该配置项的内置默认值。

### 默认设置新增项

| key | 默认 | 分组 | 说明 |
|---|---|---|---|
| default_avatar | "" | 站点 | 默认头像 URL |
| rate_limit_enabled | true | 安全 | 限流总开关 |
| login_max_attempts | 10 | 安全 | 登录窗口内次数 |
| login_window_seconds | 900 | 安全 | 登录窗口 |
| register_max_attempts | 5 | 安全 | 注册窗口内次数 |
| register_window_seconds | 1800 | 安全 | 注册窗口 |
| default_page_size | 10 | 界面 | 列表默认条数 |
| status_refresh_seconds | 10 | 界面 | 状态页刷新间隔 |

### 限流响应

HTTP 429：

```json
{"code": 429, "data": null, "msg": "尝试过于频繁，请约 16 分钟后重试"}
```

优先使用 Redis；Redis 不可用时自动降级进程内滑动窗口，不会裸放行。
