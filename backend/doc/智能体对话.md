# Agent 对话

实现位置：

- 路由：`app/routers/agent.py`
- 服务：`app/services/agent/chat.py`、`toolkit.py`、`conversations.py`
- 模型：`app/models/agent.py`
- 前端：`frontend/src/views/Chat.vue`

---

## 一、能力范围

已实现：

- 会话创建 / 列表 / 删除
- 消息持久化
- SSE 流式回复
- 文本增量、思考增量、工具调用事件
- 每轮按当前用户 AI 工具权限构建 Toolkit
- 系统提示词 + 安全提示词
- 基础文件工具限制在用户工作区
- 数据库工具受默认库/表白名单与写开关约束
- 默认不挂载 Shell（`security.allow_agent_shell=false`）

未实现：

- 对话内工具审批弹窗（当前运行时默认放行已授权工具）
- 会话续传 / 断线重连
- 附件、多模态、知识库勾选
- 技能 / MCP / 子智能体 / 超级智能体
- 上下文压缩与长期记忆

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/agent/conversations` | 本人会话列表 |

## 五、工具装配

`services/agent/toolkit.py::async_build_toolkit`：

1. 读取用户 AI 工具有效权限。
2. `basic`：Read / Write / Edit / Glob / Grep，绑定用户工作区 `backend/uploads/agents/user_{id}/workspace`。
3. `plan`：TaskCreate / TaskGet / TaskList / TaskUpdate。
4. `db` / `net` / `mail` / `mcp` / `rag`：包装 scope 工具入口。
5. `sys`：只有 `security.allow_agent_shell=true` 才挂载。
6. 数据库工具：
   - 读工具应用 `db.allowed_*` / `db.denied_*`
   - 写工具额外要求 `db.allow_write=true`
   - 默认禁止模型自传 host/user/password/path
7. 工具身份通过 `merge_identity` 注入，模型无法伪造 `user_id`。

---

## 六、安全边界

- 身份只信 JWT；SSE 路由不接收 user_id
- 安全提示词由 `security.prompt_guard_text` 提供
- 工具权限按用户生效权限装配，不在列表中的工具模型看不到
- 文件工具限定在用户工作区
- Shell 默认关闭
- 数据库默认不可读任何表、不可写
- 所有工具参数中的 `user_id` 与下划线内部键会被丢弃

## 八、已知限制

- 每轮新建 Agent，历史只拼接最近 20 条到系统提示词
- 无断线续传，刷新后只看到已落库消息
- 工具审批尚未接入
- 上下文压缩 / 记忆 / 附件未接入
- 真实工具调用依赖各工具自身凭证配置（数据库/邮箱等）

## 九、用户级 Agent 配置

新表 `user_agent_configs`：每个用户可覆盖系统 Agent 配置，或继续跟随系统默认。

字段：`use_system_default / provider / base_url / api_key / model / temperature / max_tokens / context_window / stream / system_prompt`

接口：

- `GET /api/agent/config`
- `PUT /api/agent/config`
- `DELETE /api/agent/config`（恢复跟随系统）
- `GET /api/agent/providers`
- `POST /api/agent/models`（使用当前用户配置的 Key 拉取模型）

对话优先使用用户配置；用户选择跟随系统时使用「Agent 配置」的系统默认。

## 十、工具连接配置

用户级工具配置表 `user_tool_configs`，支持：

- `email`：SMTP / IMAP / 账号 / 授权码 / 发件人 / TLS
- `db`：PostgreSQL / MySQL / MongoDB / SQLite 连接

解析顺序：用户自定义 > 系统默认。

系统默认来源：

- 邮箱：`mail.*` 系统配置
- 数据库：`db.default_*` 与数据库安全策略

接口：

| 方法 | 路径 |
|---|---|
| GET | `/api/agent/tool-config/{category}` |
| PUT | `/api/agent/tool-config/{category}` |
| DELETE | `/api/agent/tool-config/{category}` |
| POST | `/api/agent/tool-config/{category}/test` |

- 密码返回 `******`
- 提交 `******` 表示保持原值
- 测试连接：邮箱走 SMTP 登录；数据库走 scope `list_databases`
- Agent Toolkit 装配时：
  - 邮箱工具注入服务端 `email_config`
  - 数据库工具注入服务端连接，模型不能覆盖 host/user/password

## 十二、思考强度

配置项：

| key | 默认 | 说明 |
|---|---|---|
| `ai.think` | false | 是否开启思考模式 |
| `ai.thinking_budget` | 0 | 思考预算 tokens，0=模型默认 |
| `ai.reasoning_effort` | medium | low / medium / high |

- 系统默认在「Agent 配置 → 对话模型」
- 用户覆盖在「Agent 设置」
- 构建 LLM 时传入 `think / thinking_budget / reasoning_effort`
- 支持思考的模型输出 `reasoning_delta`，前端折叠展示“思考过程”
- 不同厂商支持程度不同；不支持的参数由 scope 模型工厂忽略或按 provider 映射

## 十四、附件与上下文压缩

### 附件

- `agent_attachments` 保存上传文件
- `agent_messages.attachments` 保存消息附件元数据
- 上传：`POST /api/agent/attachments`（multipart，20MB 上限）
- 支持：
  - 图片：base64 作为 `DataBlock` 传模型
  - 文本/JSON/CSV/Markdown：读取前 20000 字符拼入消息
  - 其他类型：只保留元数据并提示未解析
- 文件落盘：`backend/uploads/agents/user_{id}/attachments/`

### 上下文压缩

构建 Agent 时传入：

- `agent.context.trigger_ratio`
- `agent.context.reserve_ratio`
- `agent.context.context_buffer_ratio`

对应 scope `ContextConfig`，超过上下文阈值自动压缩。
