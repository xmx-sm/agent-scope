# Agent 对话

实现位置：

- 路由：`app/routers/agent.py`
- 服务：`app/services/agent/chat.py`、`toolkit.py`、`conversations.py`
- 模型：`app/models/agent.py`
- 前端：`frontend/src/views/Chat.vue`

---

## 一、能力范围

已实现：

- 会话创建 / 列表 / 删除
- 消息持久化
- SSE 流式回复
- 文本增量、思考增量、工具调用事件
- 每轮按当前用户 AI 工具权限构建 Toolkit
- 系统提示词 + 安全提示词
- 基础文件工具限制在用户工作区
- 数据库工具受默认库/表白名单与写开关约束
- 默认不挂载 Shell（`security.allow_agent_shell=false`）

未实现：

- 对话内工具审批弹窗（当前运行时默认放行已授权工具）
- 会话续传 / 断线重连
- 附件、多模态、知识库勾选
- 技能 / MCP / 子智能体 / 超级智能体
- 上下文压缩与长期记忆

## 二、数据表

### agent_conversations

`id / user_id / title / created_at / updated_at`

### agent_messages

`id / conversation_id / role / content / reasoning / tool_events / input_tokens / output_tokens / created_at`

`tool_events` 为 JSON 数组，前端折叠展示。

---

## 三、接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/agent/conversations` | 本人会话列表 |
| POST | `/api/agent/conversations` | 新建会话 |
| DELETE | `/api/agent/conversations/{id}` | 删除本人会话 |
| GET | `/api/agent/conversations/{id}/messages` | 消息列表 |
| POST | `/api/agent/chat/stream` | SSE 流式对话 |

SSE 事件：

- `text_delta`：`{text}`
- `reasoning_delta`：`{text}`
- `tool_start`：`{tool_call_id, tool_name}`
- `tool_result`：`{tool_call_id, name, input, output, status}`
- `done`：`{conversation_id, message_id, content}`
- `error`：`{error}`

## 四、模型配置

从系统配置读取：

| key | 用途 |
|---|---|
| `ai.provider` | 模型厂商 |
| `ai.base_url` | API 地址 |
| `ai.api_key` | API Key |
| `ai.model` | 模型 ID |
| `ai.stream` | 是否流式 |
| `ai.temperature` | 温度 |
| `ai.max_tokens` | 最大输出 |
| `ai.context_window` | 上下文窗口 |
| `ai.system_prompt` | 系统提示词 |

缺少 `ai.model` 或 `ai.base_url` 时返回 SSE `error`：「请先在 Agent 配置中填写…」。

## 五、工具装配

`services/agent/toolkit.py::async_build_toolkit`：

1. 读取用户 AI 工具有效权限。
2. `basic`：Read / Write / Edit / Glob / Grep，绑定用户工作区 `backend/uploads/agents/user_{id}/workspace`。
3. `plan`：TaskCreate / TaskGet / TaskList / TaskUpdate。
4. `db` / `net` / `mail` / `mcp` / `rag`：包装 scope 工具入口。
5. `sys`：只有 `security.allow_agent_shell=true` 才挂载。
6. 数据库工具：
   - 读工具应用 `db.allowed_*` / `db.denied_*`
   - 写工具额外要求 `db.allow_write=true`
   - 默认禁止模型自传 host/user/password/path
7. 工具身份通过 `merge_identity` 注入，模型无法伪造 `user_id`。

---

## 六、安全边界

- 身份只信 JWT；SSE 路由不接收 user_id
- 安全提示词由 `security.prompt_guard_text` 提供
- 工具权限按用户生效权限装配，不在列表中的工具模型看不到
- 文件工具限定在用户工作区
- Shell 默认关闭
- 数据库默认不可读任何表、不可写
- 所有工具参数中的 `user_id` 与下划线内部键会被丢弃

## 八、已知限制

- 每轮新建 Agent，历史只拼接最近 20 条到系统提示词
- 无断线续传，刷新后只看到已落库消息
- 工具审批尚未接入
- 上下文压缩 / 记忆 / 附件未接入
- 真实工具调用依赖各工具自身凭证配置（数据库/邮箱等）
