# Agent 对话

实现位置：

- 路由：`app/routers/agent.py`
- 服务：`app/services/agent/chat.py`、`toolkit.py`、`conversations.py`
- 模型：`app/models/agent.py`
- 前端：`frontend/src/views/Chat.vue`

---

## 一、能力范围

已实现：

- 会话创建 / 列表 / 删除
- 消息持久化
- SSE 流式回复
- 文本增量、思考增量、工具调用事件
- 每轮按当前用户 AI 工具权限构建 Toolkit
- 系统提示词 + 安全提示词
- 基础文件工具限制在用户工作区
- 数据库工具受默认库/表白名单与写开关约束
- 默认不挂载 Shell（`security.allow_agent_shell=false`）

未实现：

- 对话内工具审批弹窗（当前运行时默认放行已授权工具）
- 会话续传 / 断线重连
- 附件、多模态、知识库勾选
- 技能 / MCP / 子智能体 / 超级智能体
- 上下文压缩与长期记忆

## 五、工具装配

`services/agent/toolkit.py::async_build_toolkit`：

1. 读取用户 AI 工具有效权限。
2. `basic`：Read / Write / Edit / Glob / Grep，绑定用户工作区 `backend/uploads/agents/user_{id}/workspace`。
3. `plan`：TaskCreate / TaskGet / TaskList / TaskUpdate。
4. `db` / `net` / `mail` / `mcp` / `rag`：包装 scope 工具入口。
5. `sys`：只有 `security.allow_agent_shell=true` 才挂载。
6. 数据库工具：
   - 读工具应用 `db.allowed_*` / `db.denied_*`
   - 写工具额外要求 `db.allow_write=true`
   - 默认禁止模型自传 host/user/password/path
7. 工具身份通过 `merge_identity` 注入，模型无法伪造 `user_id`。

## 六、安全边界

- 身份只信 JWT；SSE 路由不接收 user_id
- 安全提示词由 `security.prompt_guard_text` 提供
- 工具权限按用户生效权限装配，不在列表中的工具模型看不到
- 文件工具限定在用户工作区
- Shell 默认关闭
- 数据库默认不可读任何表、不可写
- 所有工具参数中的 `user_id` 与下划线内部键会被丢弃

## 二十一、定时任务

### 数据表 `user_scheduled_jobs`

名称、指令、间隔、下次执行、日历规则、会话模式、超时、最近状态、执行次数。

### 调度

- `interval`：每任务独立间隔，最小 60 秒
- `calendar`：每周 / 每月日号 / 日期范围 + 每日多个时刻（北京时间）
- `next_run_at` 是唯一判定；全局 worker 每 60 秒扫描
- 原子 UPDATE 认领，防重复触发；同进程运行集合防重叠
- 每次执行以任务主人身份跑一轮，结果落到新会话或固定会话
- 模型用量 `source=cron`
- 支持立即执行，不改排期

### 接口

```text
GET    /api/agent/scheduled-jobs
POST   /api/agent/scheduled-jobs
POST   /api/agent/scheduled-jobs/{id}/toggle
POST   /api/agent/scheduled-jobs/{id}/run-now
DELETE /api/agent/scheduled-jobs/{id}
```

前端：Agent → 定时任务。

## 二十二、消息分支与断线续传

### 分支

`POST /api/agent/conversations/{id}/branch`，从指定消息复制到新会话，保留原会话不动。聊天消息下「分支」按钮。

### 续传

- 生成任务由 `stream_manager` 托管，客户端断开后后台继续
- `GET /api/agent/chat/resume/{conversation_id}` 重放事件
- 前端连接中断时自动重置气泡并续传
- 当前为单进程内存态；多 worker / 进程重启不保留
