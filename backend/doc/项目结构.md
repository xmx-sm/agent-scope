# 后端项目结构

> v0.20 起按“领域 → 子域”组织。路由、服务、模型、Schema 使用同一套领域命名，新增功能不再平铺到根目录。

## 三、新增功能放哪里

1. 先确定领域：账号、访问控制、系统、Agent、LLM、集成。
2. 在对应领域包下新增子域，不要直接放回包根目录。
3. 同一子域同时落到：
   - `models/<领域>/...`
   - `schemas/<领域>/...`
   - `routers/<领域>/...`
   - `services/<领域>/...`
4. 服务函数只接收一个 `params: dict`。
5. 路由只解析参数与包装响应。
6. 新增表或列：
   - 模型放对应领域；
   - 在 `core/database.py` 补幂等 `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`；
   - 更新 `数据库说明.md`。
7. 文档同步：
   - `项目结构.md`（本文件）
   - `CODE_INDEX.md`
   - `参数说明.md`
   - `接口说明.md`
   - `开发记录.md`

## 四、禁止事项

- 禁止在 `routers/` 根目录新增单文件接口。
- 禁止在 `services/` 根目录新增业务文件。
- 禁止把无关功能塞进 `__init__.py`。
- 禁止 `services/` 反向导入 `routers/`。
- 禁止 `models/` 导入 `services/`。
