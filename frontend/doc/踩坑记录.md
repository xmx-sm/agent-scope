# frontend 踩坑记录

记录前端实际遇到或验证过的问题，按「现象 → 原因 → 处理」写。

---

## A. 环境与构建

### A1. FUSE 挂载目录不能执行文件，`npm install` 失败

**现象**：

```text
Error: spawnSync .../node_modules/esbuild/bin/esbuild EACCES
```

**原因**：某些 FUSE / 特殊挂载盘，普通文件即使 `chmod +x` 也无法执行（`ls` 仍显示 644）。

**处理**：依赖安装到可执行目录，再软链回来：

```bash
mkdir -p /tmp/agent_scope_frontend
cp package.json /tmp/agent_scope_frontend/
cd /tmp/agent_scope_frontend && npm install
ln -sfn /tmp/agent_scope_frontend/node_modules \
  /path/to/agent_scope/frontend/node_modules
```

普通文件系统直接 `npm install` 即可；`node_modules` 已在 `.gitignore`。

### A2. 构建包体积告警

**现象**：`Some chunks are larger than 500 kB`。

**原因**：Element Plus 全量引入。

**处理**：当前接受；后续可用按需引入或 `manualChunks` 拆分。不影响运行。

### A3. 修改 `.env` 后不生效

**原因**：Vite 只在启动时读取环境变量。

**处理**：重启 `npm run dev`；生产需重新 build。

## B. 请求与登录态

### B1. 页面拿不到后端 `data`

**原因**：Axios 拦截器已经把 `{code,data,msg}` 解包为 `data`。

**约定**：页面直接使用返回值，不要再判断 `response.code`。

### B2. 401 后页面反复跳转

**处理**：拦截器只清理 token 并跳 `/login`；路由守卫看到无 token 直接放行登录页，不会再次请求。

### B3. 权限变更后菜单不更新

**现象**：超管收缩某用户权限后，该用户当前页面菜单仍在。

**原因**：`user` / `permissions` 缓存在 localStorage，只在登录或 `fetchMe()` 时刷新。

**处理**：收缩成功后显式调用 `auth.fetchMe()`；服务端每次请求仍实时校验，缓存只影响显示。

### B4. 临时授权页面进不去

**现象**：超管临时授予 `system.status`，用户刷新后仍看不到运行状态。

**原因**：早期路由使用 `superAdminOnly`，直接按角色拦截。

**处理**：运行状态改为 `meta.permission = 'system.status'`，由有效权限控制；用户需重新登录或刷新以拉取最新 `/auth/me`。

## C. Element Plus

### C1. 复选框值不生效

**现象**：`el-checkbox` 勾选后 `v-model` 数组没有变化。

**原因**：Element Plus 2.8 使用 `value` 作为选中值；旧写法把 `label` 当值。

**处理**：统一写 `:value="key"`，同时保留 `:label` 仅用于兼容旧版本。

### C2. 弹窗在手机上横向溢出

**处理**：全局断点内 `.el-dialog { width: calc(100vw - 24px) !important; }`，页面内再传 `:width="isMobile ? '92%' : '520px'"`。

### C3. 用户管理移动端表格难用

**处理**：同一页面维护表格与卡片两套视图，按 `isMobile` 切换，数据与操作函数复用。

### C4. 头像 URL 为空时出现破图

**处理**：`:src="auth.user?.avatar || undefined"`，为空时使用 `<el-avatar>` 的文字插槽。

## D. 路由与布局

### D1. 侧栏收缩后文字溢出

**处理**：`el-aside` 宽度过渡，菜单项 `white-space: nowrap`、`overflow: hidden`；收起时只渲染图标并用 `el-tooltip` 提示。

### D2. 移动端抽屉与桌面侧栏同时渲染

**处理**：`v-if="!isMobile"` / `v-if="isMobile"` 互斥；`resize` 时同步关闭抽屉。

### D3. 用户管理上级下拉只有当前页 10 人

**现象**：新增/编辑用户时，上级下拉缺人。

**原因**：下拉最初复用列表页数据。

**处理**：打开弹窗时单独请求 `page_size=100` 的用户列表作为选项。

### D4. `superAdminOnly` 与权限点重复判断

**约定**：

- 用户管理、默认设置：`superAdminOnly: true` + `admin.*` 权限
- 运行状态：只按 `system.status` 权限，允许临时授权进入
- 菜单过滤与路由守卫必须保持一致，否则会出现“能进但没菜单”或反之

## E. 运行状态页

### E1. 自动刷新请求堆积

**处理**：固定 10 秒 `setInterval`，请求期间 `loading` 只控制首屏；组件卸载时 `clearInterval`。

### E2. 字节 / 时长显示不直观

**处理**：前端统一格式化：

- 字节 → B/KB/MB/GB/TB，保留 1 位小数
- 运行时长 → 天/小时/分钟

### E3. 无 GPU 时页面空白

**处理**：后端返回 `gpu: []`，前端显示空状态，不报错。

---

## F. 权限页面

### F1. 收缩后把自己锁死

**风险**：用户可以收缩 `permissions.self`，之后无法进入「我的权限」恢复。

**当前处理**：收缩前二次确认；恢复只能由上级或超管操作。若后续要避免锁死，可禁止收缩 `permissions.self` 或在个人中心保留入口。

### F2. 临时授权时间选择时区

**处理**：`el-date-picker` 返回本地时间，提交时 `new Date(value).toISOString()` 转 UTC；后端按 UTC 比较。
