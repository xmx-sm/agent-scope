### 设计决策

1. **登录态快照 + 服务端真值**：本地缓存只用于首屏，进入页面后仍以 `/auth/me` 为准，角色被修改后刷新即可生效。
2. **权限驱动菜单**：菜单不是写死的角色判断（超管页除外），新增权限点后前端矩阵自动出现。
3. **桌面表格 / 移动卡片双视图**：用户管理数据量小，卡片比横向滚动表格更适合手机。
4. **不引入 UI 状态库之外的复杂度**：当前只有登录态需要跨页面共享，Pinia 足够。

### 构建说明

当前机器 `/mnt/sda2` 为 FUSE 挂载，**文件不可执行**（`chmod +x` 不生效），`esbuild` 无法在 `frontend/node_modules` 内运行。处理方式：

```bash
# 依赖安装到可执行目录，再软链回项目
mkdir -p /tmp/opencode/agent_scope_frontend
cp frontend/package.json /tmp/opencode/agent_scope_frontend/
cd /tmp/opencode/agent_scope_frontend && npm install
ln -sfn /tmp/opencode/agent_scope_frontend/node_modules \
  /mnt/sda2/qoder/qoder/agent_scope/frontend/node_modules
```

之后在 `frontend/` 正常执行 `npm run dev` / `npm run build`。这是本机环境限制，不是项目问题；普通文件系统直接 `npm install` 即可。
