# 前端页面说明

## 路由

| 路径 | 页面 | 权限 | 说明 |
|---|---|---|---|
| `/login` | Login.vue | 公开 | 登录，已登录自动跳工作台 |
| `/register` | Register.vue | 公开 | 注册；后端关闭注册时提示 |
| `/dashboard` | Dashboard.vue | dashboard | 工作台、统计、快捷入口、我的权限 |
| `/profile` | Profile.vue | profile | 修改资料与密码 |
| `/admin/users` | admin/UserManage.vue | admin.users | 用户管理（非超管不可见/不可操作超管账号） |
| `/admin/settings` | admin/Settings.vue | admin.settings + super_admin | 默认配置 + 角色权限 |

路由守卫：

1. 未登录访问受保护页面 → `/login?redirect=...`
2. 已登录访问登录/注册页 → `/dashboard`
3. 缺少 `meta.permission` 或非超管访问 `superAdminOnly` 页面 → `/dashboard`
4. 内存无用户信息时先调用 `/auth/me`，失败即清除登录态

## 页面功能

### 登录 / 注册

- 登录前读取 `/api/public/site` 展示站点名称、描述并决定是否显示注册入口
- 登录账号支持用户名 / 昵称 / 邮箱 / 手机号
- 注册成功后直接进入工作台

### 工作台

- 问候语、当前角色标签
- 超管可见统计卡片（用户总数、启用数、管理员数、普通用户数）
- 快捷入口按角色与权限过滤
- 展示当前账号权限点

### 个人中心

- 修改昵称 / 邮箱 / 手机号
- 修改密码成功后清空登录态并回到登录页

### 用户管理（超管）

- 搜索：用户名 / 昵称 / 邮箱 / 手机号
- 角色筛选、分页
- 新增用户、编辑（角色、上级、启用状态）、重置密码、删除
- 桌面端表格，移动端卡片列表
- 上级下拉来自当前页用户；编辑时排除自己

### 系统配置（超管）

- **默认配置**：按 `value_type` 渲染开关 / 数字 / 文本，逐项保存
- **角色权限**：按角色展示权限矩阵；`super_admin` 只读全选，`admin` / `user` 可编辑保存

## 登录态与权限

- `access_token` / `refresh_token` / `user` / `permissions` 存 `localStorage`
- Axios 请求自动带 `Authorization: Bearer`
- 响应 `code != 200` 统一弹出 `msg`；HTTP 401 清除登录态并跳转登录页
- 菜单和路由都由 `/auth/me` 返回的 `permissions` 驱动

## 移动端适配

- 断点：`max-width: 767px`
- `index.html` 使用 `viewport-fit=cover`，适配刘海屏安全区
- 桌面显示固定侧栏；移动端改为顶部菜单按钮 + 左侧抽屉
- 页面内边距、卡片、弹窗宽度、分页器按小屏收敛
- 用户管理在移动端切换为卡片列表
- 弹窗宽度：移动端 `calc(100vw - 24px)`，避免横向溢出
- 输入框字号沿用 Element Plus 大号尺寸，避免 iOS 自动缩放

## 待补充

- 刷新令牌自动续期（当前过期后直接回登录页）
- 权限点细化到按钮级
- 主题切换 / 暗色模式
- 移动端底部导航（当前为抽屉菜单）

## v0.2.0 页面变更

### 新增路由

| 路径 | 页面 | 权限 | 说明 |
|---|---|---|---|
| `/permissions` | MyPermissions.vue | permissions.self | 我的有效权限、临时授权、收缩自己 |
| `/team/permissions` | TeamPermissions.vue | permissions.team | 管理链下属权限收缩 |
| `/system/status` | SystemStatus.vue | system.status | 运行状态（超管或临时授权） |

### 侧栏收缩

- 顶栏左侧按钮切换展开/收起（桌面端）
- 收起后宽度 68px，仅显示图标，悬停显示文字提示
- 状态保存在 `localStorage.sidebar_collapsed`

### 个人中心头像

- 新增头像 URL 输入与实时预览
- 留空使用文字头像；后端校验 http(s) 或站内路径
- 顶栏头像同步展示

### 默认设置

- 按「站点 / 账号 / 安全 / 界面」分组展示
- 每项支持单独保存、恢复默认
- 新增限流、默认条数、状态刷新间隔等参数

### 用户管理权限弹窗（超管）

- 查看目标用户当前有效权限
- 单独授权（叠加角色权限）
- 收缩权限（只增不减）
- 临时越级授权：选择权限 + 过期时间，可包含 `system.status`

### 运行状态

- 概览：主机名、主 IP、应用运行时长、进程数
- CPU / 内存 / 磁盘进度图
- GPU 卡片（显存、利用率、温度、驱动）
- 网络收发、网卡 IP、连接数
- Redis 连接状态、版本、内存、限流后端与桶数量
- PostgreSQL 连接状态与响应耗时
- 默认 10 秒自动刷新，可关闭

### 权限模型对应关系

```text
基础权限 = 角色权限 ∪ 超管单独授权
有效权限 = (基础权限 - 收缩) ∪ 未过期临时授权
```

- 菜单与路由由 `/auth/me` 返回的有效权限驱动
- 收缩后 `auth.fetchMe()` 立即刷新菜单

## v0.3.0 菜单配置

- 「默认设置」新增 **菜单配置** Tab（仅超管）
- 菜单支持两级：一级分组、二级页面
- 可配置字段：标题、Key、路径、图标、权限点、排序、可见性、仅超管
- 图标来自 Element Plus 图标名，可选择或手动输入
- 支持上移/下移，自动重排同组 `sort_order`
- 菜单不再写死：登录后从 `/api/menus/mine` 拉取，按有效权限过滤
- 默认分组：
  - 权限管理：我的权限、团队权限
  - 系统：用户管理、默认设置、运行信息
- 默认设置新增 AI / Scope / 邮箱分组，敏感项以 `******` 回显

## v0.3.1 折叠与 AI 权限

### 菜单折叠

- 侧栏分组标题可点击折叠/展开，右侧箭头旋转
- 状态存 `localStorage.menu_groups_collapsed`

- 默认展开「站点」「账号」，其余收起
- 提供「全部展开 / 全部收起」
- 分组标题显示配置项数量

### AI 权限

- 新增 `ai.use`：普通用户与管理员默认拥有
- 新增 `ai.config`：超管专属
- 权限矩阵中 `ai.use` 可分配，`ai.config` 不进入可分配列表

## v0.3.2 菜单入口与个性化

### 默认菜单视角

| 用户 | 菜单 |
|---|---|
| 普通用户 | 工作台、我的（我的权限/菜单个性化/个人中心） |
| 上级 | 普通用户 + 管理下级 |
| 超级管理员 | 普通用户 + 运行信息 + 管理后台 |

### 管理后台 `/admin`

超管专属聚合入口，卡片进入：

- 用户管理
- 系统配置（默认设置 / 角色权限 / 菜单配置）
- 运行信息

### 菜单个性化 `/menu-settings`

- 一级菜单与子菜单都可上移/下移
- 可隐藏不需要的菜单项
- 「菜单个性化」入口固定可见，防止隐藏后无法恢复
- 保存后立即刷新侧栏
- 支持恢复默认

### 菜单显示规则

- `super_only`：仅超级管理员
- `leader_only`：仅当前用户有直接下属
- `permission`：用户有效权限必须包含该权限点
- 用户偏好：隐藏项不显示，顺序覆盖默认 `sort_order`

## v0.4.0 Agent 配置页

**路由：** `/admin/agent`（超管，权限 `ai.config`）

三个 Tab：

| Tab | 内容 |
|---|---|
| 对话模型 | 厂商、API 地址、Key、模型、温度、最大输出、上下文、流式、系统提示词 |
| 向量模型 | 厂商、API 地址、Key、Embedding 模型、维度、批大小 |
| Scope 默认 | `agent.*` / `rag.*` 默认值 |

特点：

- 厂商下拉支持预设与自定义输入
- 选择预设后自动填充 API 地址
- 「获取模型」按钮调用后端 `/admin/agent/models`，下拉显示返回的模型
- 已保存 Key 显示 `******`，保存时未修改不会覆盖
- 系统设置页只展示 `domain=system` 的配置，不再混入 AI/Scope
- 入口：管理后台 → Agent 配置

## v0.4.1 默认配置独立页面

原「系统配置」左右 Tab 已拆分：

| 菜单 | 路由 | 权限 |
|---|---|---|
| 系统设置 | `/admin/config/system` | `admin.settings` |

侧栏结构：

- 系统：用户管理、运行信息
- 默认配置：系统设置、角色权限、菜单配置、Agent 配置
- 默认配置为独立分组，展开后是纵向子菜单
- 不再提供管理后台聚合页

### Scope 配置折叠

Agent 配置 → Scope 默认 按模块折叠：

- 上下文压缩
- 运行时注入
- 上下文卸载
- 能力开关（Skills / Plan / MCP）
- RAG 检索

默认全部收起，支持「全部展开」；避免 18 项长列表一次铺开。
